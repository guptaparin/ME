# Parin's Workbench — website

A static site: `index.html` plus the `assets/` folder. No build step.

## Put it online (free)
**Vercel:** vercel.com → Add New → Project → drag this folder in (or push it to a GitHub repo and import it). Done.
**GitHub Pages:** create a repo named `guptaparin.github.io`, upload everything in this folder, then Settings → Pages → Deploy from branch `main`. It goes live at https://guptaparin.github.io

Custom domain (optional): buy one (e.g. parin.design) and add it in Vercel → Project → Domains, or in GitHub Pages settings.
